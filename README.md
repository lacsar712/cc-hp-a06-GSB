# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

异物检出必须点名：炮制员在「异物词条」页维护词条（初始含草屑、砂粒），开炒时至少点名词条中的一项，点名原文随文书保存；事后改词条表不影响已存点名，一项都不点则拒写。质检员能看词条与已存点名，不能改词条。顶栏挂「异物词条」链，落地页含词条维护、点名区、已存点名一览。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 顶栏进「异物词条」，词条含草屑、砂粒；落地页有词条维护、点名区、已存点名一览。
3. 点名区写白芍并点名草屑，写入成功，已存点名一览出现「白芍 · 点名 草屑」。
4. 一项都不点直接写入，被拒（零点名拒写）。
5. 把草屑改名后，已存点名仍显示草屑原文。
6. 再写一条温度 200 的清炒（需点名），结论仍是未放行。
7. checker 能看词条与已存点名，看不到写入按钮，也不能改词条。
